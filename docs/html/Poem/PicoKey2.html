pico-fido のファームウェアをビルドする†

  • pico-key は ラズピコ/ラズピコ２基板用のUSBセキュリティキー を実現するオープンソースのファームウェアです。
  • githubで公開されています。
  • アマゾンなどでUSBセキュリティキーを購入すると大体5000円程度します
  • ラズピコ基板なら、（かつ、電子工作マニアの方とさせていただきますが）あなたの机の引き出しに２，３枚は常備されていることでしょう。
  • つまり、無料です。（市販キーと比較すると、壊れやすいけどね）

：

  • あ、念のために書いておきますが、FIDO2キーをラズピコに書き込むだけなら、ビルド済バイナリーをDLして、BOOTボタン押して、uf2ファイルをドラッグどろっぴするだけで書き込めます。
  • ビルドするというのは、つまり、あれです。（省略されました）

：

  • 前提条件
    Ubuntu26.04 LTSを使用
  • 事前準備
    $ sudo apt install cmake python3 build-essential gcc-arm-none-eabi libnewlib-arm-none-eabi libstdc++-arm-none-eabi-newlib

ソースコード取得†

  • 以下の環境変数は適宜設定して、.bash_profile などに記述しておくと良い 
    # PICO_SDK は、ywork直下に置いた.
export PICO_SDK_PATH=~/pico-sdk
  • クローン 
    git clone https://github.com/raspberrypi/pico-sdk
cd ~/pico-sdk
git submodule update --init --recursive
cd ~/
git clone https://github.com/polhenarejos/pico-fido
cd ~/pico-fido
git submodule update --init --recursive

SSL鍵をあらかじめ作る†

  • openssl で適当に作る。置き場所は ~/
  • bash 
    PRIVATE_KEY=ec_private_key.pem
PUBLIC_KEY=ec_public_key.pem

openssl ecparam -genkey -name secp256k1 -noout -out $PRIVATE_KEY
openssl ec -in $PRIVATE_KEY -pubout -out $PUBLIC_KEY

pico-fidoのビルド†

cd ~/pico-fido
./build_pico_fido.sh

以下のuf2ファイルが作られる

~/pico-fido/release/pico_fido_pico-8.2.uf2
~/pico-fido/release/pico_fido_pico2-8.2.uf2
  • pico2 が付いてるほうのuf2は、ラズピコ２基板用のファーム。

蛇足†

  • ラズピコ基板が壊れやすい問題（電子部品や端子がむき出し）は、ミンティアケースなどに入れるとよいでしょう
  • （どっちかというとフリスクよりもミンティア派です）
  • また、万一の基板故障やファーム消去に備えて、picotoolで、FlashROMの内容を全部PCに保存しておくことをお勧めします。 
     $ picotool save -a
    これは、ファーム消去からの復元には使えますが、別の基板へ移すのは無理なので、（どうしてもやりたければ、ファームウェアビルド時にFlashROMの ID を固定してしまう、という手が）

ファームウェアビルド時にFlashROMの ID を固定したい？†

  • pico-fido/pico-keys-sdk/src/serial.c: 
    void serial_init(void) {
   ・・・
  • ここで、pico_serial という8byteのflashROMのIDを保持する構造体を受け取っているので、受け取り後、自分の好きなIDに固定する
  • こうやって焼いたファームを picotool save -a で全領域クローンすると、パスキーのクレデンシャルもUSBログインPINもコピーされる。
  • picotool save -a でセーブしたイメージをパソコンにバックアップしておけば、最悪、基板が壊れた場合でも別のラズピコ（初代）を買ってきてキーは復元できる。
  • ラズピコ紛失した場合は、予備の、もしくはクローンしたキーを使用して、大事なアカウントを先に別のキーやログイン手順に切り替えたのち、登録していたパスキーを全部無効化していく必要がある。 （もちろん、市販のUSBキーを紛失した場合でも同じである）
  • 違いは、ラズピコのほうが壊れやすい、ということと、間違って別のファームを書き込んでしまう危険性と、ROMが吸い出せてしまう問題、かなぁ・・・
